# Project-Management-System
A comprehensive desktop/web-based Project Management System designed to improve collaboration between employees, team leaders, project managers, and administrators. The system helps organizations manage projects, monitor employee performance, assign tasks, track working hours, and generate reports efficiently.

# Project Overview
The Project Management System provides a role-based environment where each user has access to specific features according to their responsibilities.
The system includes four main modules:
- Employee Module
- Team Leader Module
- Project Manager Module
- Admin Module
The goal of the system is to simplify project workflow, enhance productivity, and improve communication between team members and management.

# Features
👨‍💼 Employee Module
Employees can:
- Record daily entry and exit times.
- Automatically calculate monthly working hours.
- Submit Leave requests.
- View penalties or warnings.
- View assigned project tasks.
- Mark tasks as completed after finishing them. (30% progress - 50% progress - 100% progress)

👨‍💻 Team Leader Module
Team Leaders can:
- Manage employees within their team.
- Assign tasks to employees.
- Monitor and review completed tasks.

📊 Project Manager Module
Project Managers can:
- Track the overall project completion percentage.
- Generate reports about employee performance.
- Send feedback and reports to team leaders.

⚙️ Admin Module
Administrators can:
- View all projects in the system.
- Add new users.
- Update user information.
- Delete users.
- Manage different user roles and permissions.

# System Objectives
- Improve project organization and tracking.
- Enhance communication between departments.
- Monitor employee productivity and attendance.
- Simplify task management.
- Provide accurate reporting and project progress analysis.

# Technologies Used
- Java
- JavaSwing (for GUI)
- TextFiles to store data

# Expected Outcomes
- Better project monitoring.
- Increased employee accountability.
- Faster task tracking and reporting.
- Organized workflow management.
